GODLIKE CAMPAIGN OVERHAUL - HAMMER AND BACKPACKS
Version: 4.2
Game: Red Faction Guerrilla Re-Mars-tered (PC, offline)

INSTALLATION
1. Close the game. Back up your saves.
2. Find the game folder containing misc.vpp_pc and table.vpp_pc.
3. Back up both existing VPP files.
4. Extract the V4.2 download and replace BOTH VPP files in that folder.
5. Test on a separate save before playing important missions.

This is a complete replacement package. Earlier versions and the original
Ultimate Mod download are not required. RSL is not required for these VPPs.
Manual installation; no mod-manager-specific installer is included.

UNINSTALLATION
Close the game and restore both backed-up VPP files. A storefront's verify/
repair function can restore game files but may overwrite other replacements.

COMPATIBILITY
Other mods replacing either VPP should be treated as conflicting. Combining
them requires merging their underlying changes and repacking the archives.
Backpack definitions are shared with multiplayer/Wrecking Crew; this release
is intended for offline play. No multiplayer validation has been performed.

TESTING STATUS
Configuration and archive validation passed. In-game testing is still needed.
Actual flight height/duration, movement speed, Rhino distance/cancellation,
campaign NPC healing and Stealth/Vision AI behavior are not confirmed.
Fuel-based time estimates assume a normalized tank and no active regeneration
or engine/upgrade modifiers; they are not measured gameplay results.
Powerful attacks and physics can still harm hostages and mission objectives.
Save behavior, DLC encounters and mod combinations have not been fully tested.
